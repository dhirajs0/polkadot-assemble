02
The idea
What if the backend were the network?
Your dApp’s backend can be the network itself: private messaging, storage and personhood, through a light client.
…and you run no servers to do it.
Optional helpers exist (call relays, the dot.li web gateway, onboarding), run by the Polkadot Community Foundation. None is trusted for correctness.
